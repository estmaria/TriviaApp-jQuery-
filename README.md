# TriviaApp-jQuery-
This is a simple and interactive Trivia App built using HTML, CSS, and JavaScript (with the jQuery framework). It uses the Open Trivia Database API to fetch trivia questions based on user-selected preferences.

## How It Works
1. Choose your quiz settings: difficulty, category, question type (Multiple Choice or True/False), and the number of questions.

2. Click Start to fetch trivia questions from the API.

3. Answer each question — the next one will appear as soon as you respond.

4. At the end, your score will be displayed.

5. Click Play Again to restart the game with new parameters!
